How it works

From a process on paper to work getting done

1

Define

Describe the steps, the roles and the order once. Each change is saved as a new version.

2

Start

Every real case gets its own live copy, with each step given to the right person.

3

Run

People act on their steps. The engine allows or refuses each action and routes the work onward.

4

Report

Every change is recorded, so you can see progress, workload and exactly what happened.
