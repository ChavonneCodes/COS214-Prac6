Detailed Description

Represents a call to another workflow definition within the current blueprint.

Unlike a StageDefinition which contains its children inline, a SubProcessDefinition acts as a portal or reference. It does not contain internal nodes; instead, it points to a completely separate WorkflowDefinition by ID and version.

When the engine reaches this node during execution, it pauses the current workflow and runs the referenced definition as a nested instance.
