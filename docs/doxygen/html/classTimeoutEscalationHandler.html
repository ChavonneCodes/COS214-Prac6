HandlerResult TimeoutEscalationHandler::handleRequest ( Request & request)
overrideprotectedvirtual

Processes a timeout request by attempting to escalate a work item.

The handler first checks whether the request action is "TIMEOUT". Requests with other actions are passed to the next handler.

If no work item has been supplied, the request is rejected. If the request refers to a different work item, the handler returns HandlerResult::Continue.

Work items in the Completed, Rejected, Cancelled, or Failed states cannot be escalated. For other states, the handler delegates the state transition to WorkItem::escalated().

If escalation succeeds, the request's current state is updated to "Escalated", and the handler returns HandlerResult::Handled. If escalation is not permitted, the handler returns HandlerResult::Rejected.

Parameters
requestReference to the timeout request being processed.
Returns
HandlerResult::Continue if the request is not a timeout or refers to a different work item; HandlerResult::Handled if escalation succeeds; HandlerResult::Rejected if escalation cannot proceed.
