Detailed Description

Declares one visit method per concrete runtime node.

A node's accept() calls the visit method for its own class (double dispatch), so a visitor always knows exactly what kind of node it has without any dynamic_cast. New operations over a running workflow (reports, statistics, bulk actions) are added as new visitors, without changing WorkItem, StageInstance or SubProcessInstance.

Traversal: a StageInstance calls visitStage(), then passes the visitor to each child in order, then calls leaveStage(). Leaves call only their own visit method.
