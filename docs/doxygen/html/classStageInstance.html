Detailed Description

Represents a live, running instance of a workflow stage.

The StageInstance is the runtime counterpart to the static StageDefinition. It acts as a container for other runtime components (WorkItems or nested StageInstances).

It holds a reference to its blueprint (the StageDefinition) to know what it is supposed to do, but it maintains its own mutable state and dynamically owns its child runtime components.
