Detailed Description

Defines the AssignCommand class.

ConcreteCommand that gives a work item to a participant. It moves an Available or Escalated item to Assigned, binding the participant as owner and counting the item in their workload. It is refused in any other state, or when the participant is missing. execute() saves a snapshot first and restores it if the action is refused; undo() restores the last snapshot (state, owner and workload).
