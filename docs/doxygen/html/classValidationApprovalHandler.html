HandlerResult ValidationApprovalHandler::handleRequest ( Request & request)
overrideprotectedvirtual

Validates a request before allowing it to continue.

Calls Request::isValid() to determine whether the request contains the required information.

If validation fails, an error message is displayed and the request is rejected. If validation succeeds, a confirmation message is displayed and the request is passed to the next handler for further processing.

Parameters
requestReference to the request being validated.
Returns
HandlerResult::Rejected if the request is invalid; HandlerResult::Continue if validation succeeds.
