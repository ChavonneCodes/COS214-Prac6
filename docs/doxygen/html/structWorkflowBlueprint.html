Detailed Description

A Data Transfer Object (DTO) carrying the raw configuration for a workflow.

This struct is populated by the client (e.g., from a TUI or a JSON file) and passed to the WorkflowDirector and ConcreteWorkflowBuilder. The Builder reads this data to instantiate the immutable WorkflowDefinition product, handling the complex memory management of the Composite tree.

◆ rootTreeData

WorkflowNodeData WorkflowBlueprint::rootTreeData

The raw data for the Composite tree structure.

This represents the hierarchical layout (Stages containing Activities/SubProcesses). It is optional, as a user might choose to build a flat workflow using only the 'activities' vector above.
