Detailed Description

ConcreteCommand that hands a work item over for someone else to pick up, moving an Available, Assigned or In_Progress item to Escalated and releasing its owner. It is refused in any other state. The timeout handler submits it through the engine, so escalations appear in the history. execute() saves a snapshot first and restores it if the action is refused; undo() gives the item back to its previous owner.
