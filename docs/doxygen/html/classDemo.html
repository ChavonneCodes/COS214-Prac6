Detailed Description

The parts shared by every case: one engine and one run loop.

Constructor & Destructor Documentation

◆ Demo()

Demo::Demo ( )
inline

Constructs the demo and attaches its observers to the bus.

The bus stores raw pointers to audit, decisions and trace. The Demo owns them as members and they are declared before use, so they outlive the bus's use of them. The bus never deletes them.
