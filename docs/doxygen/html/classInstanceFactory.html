Detailed Description

A Simple Factory that creates runtime nodes from definition nodes.

This class bridges the gap between the static Definition tree (Composite) and the live Runtime tree. It uses dynamic type checking to determine whether a given WorkflowComponent is an Activity, Stage, or SubProcess, and instantiates the corresponding RuntimeComponent.

It supports eager instantiation: it recursively builds the entire tree at once.
