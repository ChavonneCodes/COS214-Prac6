Detailed Description

Represents a single running execution of a workflow blueprint.

While a WorkflowDefinition is shared and read-only, a WorkflowInstance is unique to one specific case (e.g., "project-approval-1"). It maintains its own state, its own data payload (e.g., budget amounts), and its own dynamically growing Runtime Composite tree.

Note
This class takes ownership of the runtime tree pointer (root). It is responsible for deleting the tree when the instance is destroyed.
