Detailed Description

ConcreteCommand that abandons a work item, moving it from any non-final state to Cancelled. The owner, if any, stays on record but the item stops counting towards their workload. Completed and Cancelled items refuse it. execute() saves a snapshot first and restores it if the action is refused; undo() restores the last snapshot, which also puts the workload back.
