Detailed Description

Stores every version of every WorkflowDefinition in memory.

Used by the WorkflowEngine (Facade) to look up definitions. Keeping every version lets a running instance stay pinned to the version it started with, while new instances use the latest version.

The repository owns the definitions it stores. It works with pointers because WorkflowDefinition cannot be copied.
