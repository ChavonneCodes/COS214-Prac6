Detailed Description

Represents a live, running instance of a sub-process call.

The SubProcessInstance is the runtime counterpart to the SubProcessDefinition. While it acts as a Leaf node within the parent runtime tree (it has no children of its own in that tree), it internally manages a completely separate nested WorkflowInstance.

When this node becomes active, it pauses the parent workflow, executes the called definition, and returns the output data to the parent once complete.
