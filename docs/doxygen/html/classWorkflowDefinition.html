Detailed Description

The immutable blueprint of a workflow process.

This class acts as the final Product of the Builder pattern. It holds a flattened list of all roles, transitions, and approval chains, as well as the root pointer to the hierarchical Composite tree of stages and activities.

Once built, it is treated as read-only. Instances created from this definition reference it by ID and version.

◆ cloneWithVersion()

WorkflowDefinition * WorkflowDefinition::cloneWithVersion ( int newVersion) const

Creates an editable copy of this definition under a new version (Prototype pattern).

The copy has the same definition id and name, copies of every role, activity, transition and approval chain, and a deep copy of the Composite tree (made with WorkflowComponent::clone()). Only the version number differs. Editing the copy (setRoot, addChild on its tree, addRole, ...) never changes this definition, so a team can tweak a workflow without rebuilding it with the Builder.

Note
The caller owns the returned pointer (for example by passing it to InMemoryDefinitionRepository::save, which stores it).
Parameters
newVersionThe version of the copy. Must differ from getVersion().
Exceptions
std::invalid_argumentif newVersion equals this definition's version.
Returns
A newly allocated independent WorkflowDefinition.
