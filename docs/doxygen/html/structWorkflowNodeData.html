Detailed Description

A raw data representation of a single node in the workflow hierarchy.

This struct is designed to be populated by the user (e.g., via a TUI or JSON file) and passed to the ConcreteWorkflowBuilder. The Builder recursively converts this raw data into instantiated StageDefinition, ActivityDefinition, and SubProcessDefinition objects.
