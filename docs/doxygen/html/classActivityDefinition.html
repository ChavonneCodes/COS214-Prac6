Detailed Description

Represents a single leaf node (activity) in the static Workflow Definition tree.

Represents a single activity (task) in the workflow definition.

Part of the Composite pattern, this class defines a specific piece of work that must be performed within a workflow.

This class acts as a Leaf in the Composite pattern. It holds the step's ID, human-readable name, the ID of the role required to perform it, and an optional ID for an associated approval chain.
