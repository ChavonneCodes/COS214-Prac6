HandlerResult RoleApprovalHandler::handleRequest ( Request & request)
overrideprotectedvirtual

Processes an approval request by checking its required role.

If the request action is not "APPROVE", the handler returns HandlerResult::Continue so another handler can process it.

If the request's required role ID matches this handler's role ID, the handler reports the match and returns HandlerResult::Handled.

If the role IDs do not match, the handler reports that it cannot process the requested role and returns HandlerResult::Continue, allowing the request to pass to the next handler.

Parameters
requestReference to the request being processed.
Returns
HandlerResult::Continue if the action is not APPROVE or the role does not match; HandlerResult::Handled if the required role matches.
