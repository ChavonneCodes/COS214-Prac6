Detailed Description

This is the State participant for a work item's life cycle. Every action a work item can be asked to perform (assign, start, complete, reject, cancel, escalate, fail, makeAvailable) is a virtual method that refuses by default: it prints "Invalid State Transition" and returns false. Each concrete state overrides only the actions it allows, so the legal transitions are defined by which methods a state overrides and not by conditionals in WorkItem. The class also declares the protected helpers (transition, bind, release, finish) through which a state changes the item's state, owner and workload, and the clone() used to save snapshots for the Memento.
