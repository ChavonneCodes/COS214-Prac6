Detailed Description

The Concrete Builder in the Builder pattern.

It provides a fluent interface (returning *this) to allow the Director or Client to construct a workflow step-by-step. When build() is called, it recursively instantiates the Composite tree from the raw WorkflowNodeData and packages it together with the flat lists (roles, transitions, etc.) into a WorkflowDefinition.
