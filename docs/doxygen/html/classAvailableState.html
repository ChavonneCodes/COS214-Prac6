Detailed Description

ConcreteState for a work item that has been released and is waiting for an owner. It allows assign (binds the participant, counts the item in their workload and moves to AssignedState), escalate (moves to EscalatedState) and cancel (moves to CancelledState). assign is refused when no participant is given.
