Detailed Description

The code both demo scenarios share: one engine and one run loop.

Demo::run() starts a case, walks the routing and produces the reports. It is the same for every process. A Scenario supplies only what is different, which is the point of the demo: TIVIDY is generic, the scenarios are just data.
