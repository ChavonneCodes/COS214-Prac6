◆ authorise()

HandlerResult ApprovalHandler::authorise ( Request & request)

Processes a request through the chain of responsibility.

Calls handleRequest() to allow the current handler to process the request. The returned result determines what happens next:

  • HandlerResult::Handled: The request was handled successfully, and processing stops.
  • HandlerResult::Rejected: The request is rejected, and processing stops.
  • HandlerResult::Continue: The request is passed to the next handler, if one exists.

If the request must continue but no next handler is available, the method reports that no handler could authorise the request and returns HandlerResult::Rejected.
