Detailed Description

Represents a routing rule (edge) between two activities in a workflow.

While the Composite tree defines the structure (what stages and activities exist), the TransitionDefinition defines the flow (what order they execute in). It is evaluated by the RoutingStrategy at runtime to determine the next step.
