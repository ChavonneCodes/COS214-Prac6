Detailed Description

Defines the WorkflowComponent abstract base class.

Part of the Composite pattern: this represents the base Component (node) in the static workflow definition tree.

Also the Prototype in the Prototype pattern: every node can clone() itself (deep copy), so an existing definition tree can be duplicated and edited without rebuilding it from scratch.
