Detailed Description

Represents a grouping of work (a stage) within the static workflow blueprint.

A stage acts as a container for other WorkflowComponents. It can hold individual ActivityDefinition leaves, or even other nested StageDefinition objects, allowing for deeply nested workflow structures.

As a Composite, it owns its children and is responsible for deleting them.

◆ clone()

StageDefinition * StageDefinition::clone ( ) const
overridevirtual

Creates a deep copy of this stage and everything below it (Prototype pattern).

Because a stage owns its children through raw pointers, copying the pointers would make two stages delete the same objects. Instead every child is cloned (recursively, through its own clone()), so the copy owns a completely separate subtree. Nested stages, activities and sub-processes are all duplicated.

Note
The caller owns the returned pointer.
Returns
A new StageDefinition with the same id and name and cloned children.
